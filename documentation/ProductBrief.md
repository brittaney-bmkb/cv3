# Product Brief

## Product Summary
CookViewer is a parcel viewer that enables residents and staff to search, inspect, and compare Cook County parcel data. The application focuses on map-driven parcel discovery with supporting panels for property details, nearby/comparable properties, and export/print workflows.

## Primary Goals
- Provide fast parcel search by PIN and address.
- Enable map-based parcel selection and comparison workflows.
- Surface property details and related contextual data in accessible panels.
- Support printing and exporting of parcel data.
- Offer multilingual support for core UI and help content.

## Target Users
- Residents searching for parcel details.
- County staff who need to verify parcels and run comparisons.
- GIS analysts exporting parcel data for reporting.

## Key Differentiators
- Tight integration with ArcGIS services and County datasets.
- Multi-panel layout optimized for map-centric workflows.
- Built-in export and print capabilities.

## Constraints and Assumptions
- The application depends on ArcGIS Online/Portal services for map layers, data dictionaries, and translations.
- Performance is currently influenced by the size of the referenced WebMap and the number of layers it loads.
- Accessibility compliance must align with current ADA Title II web requirements and WCAG 2.1 AA expectations.
